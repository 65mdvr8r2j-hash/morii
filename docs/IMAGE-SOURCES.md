# แหล่งที่มาของภาพ

ภาพตัวอย่างจากกล้องนำเข้าจากอัลบั้ม Drive ที่เจ้าของร้านให้ไว้:
https://drive.google.com/drive/folders/1-9L6rcsXpkD9mD05FCnRoqm243i2zljJ

รายละเอียดรายไฟล์อยู่ใน `photo-sources.json` ภาพรีวิวไม่ได้ถูกสร้างขึ้นแทนลูกค้า ช่อง `reviews` ยังว่างและจะแสดงเมื่อร้านเพิ่มภาพรีวิว

ภาพตัวกล้องที่ใช้บนการ์ดและหน้าแรกมาจาก Canon Camera Museum เพื่อประกอบชื่อรุ่น ไม่ใช่ภาพสภาพหรือสีของกล้องตัวที่ร้านปล่อยเช่า สามารถแทนที่ด้วยภาพสินค้าของร้านในไฟล์ `content.js` และรูปหน้าแรกใน `index.html` ได้
